## 5. ضوابط التنفيذ الحاكمة (Execution Governance)

1. **حظر التنفيذ المباشر (No Direct Code Changes):** لا يُنفذ أي تعديل على ملفات الكود أو القوالب أو مسارات التوجيه قبل الحصول على موافقة خطية على هذا السجل.
2. **العزل في الفروع (Branch Isolation):** يتم إنشاء فرع مستقل لكل مهمة (`feature/...` أو `fix/...`) متفرعاً من `main`.
3. **الاختبار الإلزامي (Mandatory QA Gates):** لا يجوز دمج أي مهمة إلا بعد اجتياز:
   - `npm run validate` (3,211 اختبار محلي بنسبة نجاح 100%).
   - `node scripts/validate-production.cjs` (185 فحصاً حياً على خادم الإنتاج).
4. **حظر النشر اليدوي:** الاعتماد التام على النشر الآلي لـ Cloudflare Pages المرتبط بفرع `main` فقط بعد التدقيق.
